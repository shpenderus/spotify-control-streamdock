Плагин для устройств, совместимых с **StreamDock**: Mirabox Stream Dock (софт StreamDock / HotSpot), Ajazz StreamDock и аналогичные. Подключается к вашему аккаунту Spotify через официальный Web API — ничего не парсит, не ломается от обновлений приложения.

## ✨ Возможности

| Кнопка | Что делает |
| --- | --- |
| ▶ **Плей/Пауза** | Пауза/воспроизведение + **обложка текущего трека** прямо на кнопке. Настраивается: название, исполнитель, время, размер шрифта, цвет времени, иконка и тонкий зелёный **прогресс-бар** |
| ℹ️ **Сейчас играет** | Обложка, название, исполнитель, время, прогресс-бар — выбираете, что показывать, и размер шрифта |
| ⏭ **Следующий / Предыдущий** | Следующий — переключение; Предыдущий — возврат в начало трека (если играет >3 с), повторное нажатие — на предыдущий |
| ❤️ **Лайк** | Ставит/убирает лайк, **реальное состояние видно на кнопке** (серое сердечко → зелёное) |
| 🔁 **Повтор** | Выкл → один трек → плейлист, состояние на кнопке |
| 🔀 **Перемешивание** | Вкл/выкл, состояние на кнопке |
| 🎚 **Перемотка (энкодер)** | Плавная перемотка внутри трека (5 сек за шаг, официальный `PUT /me/player/seek`), на дисплее — текущее время |
| 🎵 **Треки (энкодер)** | Следующий/предыдущий трек вращением |
| 🔊 **Громкость (энкодер)** | Громкость ±2% за шаг, на дисплее — уровень |
| 📋 **Плейлист** | Нажатие запускает выбранный в настройках плейлист (включая «Любимые треки»); на кнопке — его название |

Ещё:
- 🏃 **Бегущая строка** — длинные названия плавно прокручиваются, если не помещаются в кнопку.
- 🎨 **Авто-контраст текста** — плагин анализирует яркость обложки и сам делает текст чёрным или белым, чтобы он не сливался с картинкой.
- 🟢 Иконки в зелёном стиле Spotify (#1DB954), тёмный минималистичный дизайн.
- 🔐 Авторизация в один клик: плагин сам поднимает локальный сервер и ловит ответ Spotify, токены обновляются автоматически (~раз в 6 месяцев вход не нужен).
- ⚡ Кнопки обновляются за 1–2 секунды, работают с любым устройством, где играет Spotify (ПК, телефон, колонка).
- ⏱️ **Адаптивный поллинг** — чем дольше играет трек, тем реже плагин опрашивает API (бережёт лимиты); в конце трека опрос ускоряется, чтобы обложка следующего появилась сразу.

## 📦 Быстрый старт

1. Скопируйте папку нужной версии в каталог плагинов:
   - **Windows:** `C:\Users\ВАШЕ_ИМЯ\AppData\Roaming\HotSpot\StreamDock\plugins`
   - **macOS:** `Библиотека → Application Support → HotSpot → StreamDock → plugins`
2. Полностью перезапустите StreamDock (из трея).
3. В списке действий появится категория **Spotify** — перетащите кнопки на панель.
4. В настройках любой кнопки укажите **Client ID** и **Client Secret** своего Spotify-приложения и нажмите **«Войти через Spotify»**.

<details>
<summary>🔧 Как создать приложение Spotify (один раз)</summary>

1. Откройте [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard) и войдите под своим аккаунтом.
2. **Create app** → любое название (например, `StreamDock Control`), любое описание.
3. В настройках приложения (Edit settings) в поле **Redirect URIs** добавьте:
   ```
   http://127.0.0.1:8888/callback
   ```
   ⚠️ Только этот формат (`127.0.0.1` + порт). Адрес `http://localhost:...` Spotify больше не принимает.
4. Скопируйте **Client ID** и **Client Secret** из карточки приложения.

</details>
