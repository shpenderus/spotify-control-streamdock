# Spotify Control — плагин для StreamDock / Mirabox

Плагин для управления **Spotify** через официальный Web API.
Совместим с устройствами Mirabox Stream Dock (софт StreamDock / HotSpot), Ajazz StreamDock и другими, поддерживающими плагины StreamDock.

## Возможности

| Кнопка | Что делает |
| --- | --- |
| **Плей/Пауза** | Пауза/воспроизведение. Показывает **обложку текущего трека**. Можно включить подпись (название, исполнитель, время), настроить размер шрифта, **цвет времени**, **иконку play/pause** (по умолчанию выключена, зелёная как остальные кнопки) и **прогресс-бар** (тонкая зелёная полоса снизу) |
| **Сейчас играет** | Отображает обложку, название, исполнителя и время трека. В настройках кнопки можно выбрать, **что именно показывать** (обложка / название / исполнитель / время / **прогресс-бар**), **размер шрифта** (6–30) и **цвет времени**. Нажатие — плей/пауза |
| **Следующий трек** | Переключает на следующий трек |
| **Предыдущий трек** | Переключает на предыдущий трек |
| **Лайк** | Ставит/убирает лайк текущему треку, состояние видно на кнопке (серое сердечко → зелёное). Пока статус неизвестен или у токена нет прав — показывается сердечко с вопросиком |
| **Повтор** | Циклически переключает повтор: **выкл → один трек → плейлист**, состояние видно на кнопке |
| **Перемешивание** | Включает/выключает перемешивание, состояние видно на кнопке |
| **Перемотка (энкодер)** | Для устройств с энкодером: вращение — плавная перемотка внутри трека (1 шаг = 5 секунд, через официальный API `PUT /me/player/seek`), нажатие — плей/пауза. На дисплее энкодера показывает текущее время трека |
| **Треки (энкодер)** | Для устройств с энкодером: вращение — следующий/предыдущий трек, нажатие — плей/пауза |
| **Громкость (энкодер)** | Для устройств с энкодером: вращение — громкость ±2% за шаг (официальный API `PUT /me/player/volume`), нажатие — плей/пауза. Показывает текущий уровень громкости |

- Иконки в зелёном стиле Spotify (#1DB954), тёмный минималистичный дизайн.
- Длинные названия и исполнители **прокручиваются бегущей строкой**, если не помещаются в кнопку.
- Текст накладывается прямо на обложку (без тёмного фона).
- Цвет текста времени настраивается (по умолчанию зелёный Spotify), применяется кнопкой «Применить».
- **Авто-контраст текста** (по умолчанию включён): плагин анализирует яркость обложки и делает текст чёрным или белым, чтобы он не сливался с картинкой. Выключите — и текст вернётся к классическим цветам.
- При нажатии содержимое кнопки на мгновение слегка уменьшается («вдавливается») — лёгкий эффект нажатия без смены цвета.
- Авторизация полностью автоматическая: плагин поднимает локальный сервер и сам ловит ответ Spotify — ничего копировать не нужно.
- Токен обновляется автоматически, вход нужен один раз (~раз в 6 месяцев).

## Установка

1. Скопируйте папку `com.spotify.control.sdPlugin` в каталог плагинов:
   - **Windows:** `C:\Users\ВАШЕ_ИМЯ\AppData\Roaming\HotSpot\StreamDock\plugins`
   - **macOS:** `Библиотека → Application Support → HotSpot → StreamDock → plugins`
2. Перезапустите StreamDock (полностью, из трея).
3. В списке действий появится категория **Spotify** — перетащите нужные кнопки на панель.

## Настройка приложения Spotify (один раз)

1. Откройте [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard) и войдите под своим аккаунтом.
2. **Create app** → название любое (например, `StreamDock Control`), описание любое.
3. В настройках приложения (Edit settings) в поле **Redirect URIs** добавьте:
   ```
   http://127.0.0.1:8888/callback
   ```
   ⚠️ Только этот формат (`127.0.0.1` + порт). Адрес `http://localhost:...` Spotify больше не принимает.
   Сохраните. Приложение можно оставить в Development Mode.
4. Из карточки приложения скопируйте **Client ID** и **Client Secret**.

## Подключение аккаунта

1. Откройте настройки любой кнопки плагина (правый клик → настройки).
2. Вставьте **Client ID** и **Client Secret**. Redirect URI оставьте как есть (если меняли — укажите тот же, что добавили в Spotify).
3. Нажмите **«Войти через Spotify»** — откроется браузер. Подтвердите доступ, вкладка закроется сама (покажется «Вход выполнен»).
4. Статус сменится на «Подключено» — кнопки заработают.

> Если Spotify вернёт ошибку «Invalid redirect URI» — проверьте, что адрес в поле плагина **точно совпадает** с адресом в настройках приложения Spotify (включая порт).

## Примечания

- Управление воспроизведением (плей/пауза, следующий/предыдущий, повтор, перемотка) требует **Spotify Premium**.
- Перемотка работает через официальный API Spotify (`PUT /v1/me/player/seek`) — в отличие от Yandex-плагина, которому приходится управлять ползунком прямо в веб-плеере.
- Лайки используют эндпоинты библиотеки, которые в справочнике API не требуют Premium (нужны только скоупы `user-library-read` / `user-library-modify`). Однако на главной странице Web API Spotify есть общее примечание о необходимости Premium, поэтому на бесплатном тарифе лайки официально не гарантированы. Статус лайка кэшируется: при запуске StreamDock кнопка сразу показывает правильное состояние.
- **Лайки используют старые эндпоинты `/v1/me/library`** (как в официальном плагине MiraBox): у части аккаунтов современные `/v1/me/tracks` отвечают 403, хотя права на месте. Плагин пробует новые эндпоинты, при ошибке автоматически переключается на старые и запоминает их.
- Статус лайка всегда подтверждается реальным ответом Spotify (запросы сериализованы, без гонок), а при нажатии с неизвестным статусом плагин сначала узнаёт реальный статус и только потом переключает — кнопка больше не «врёт» и не снимает лайк вслепую.
- **Если кнопка лайка показывает сердечко с вопросиком** — статус неизвестен: либо ещё загружается, либо оба эндпоинта библиотеки отвечают 403 (нет права `user-library-read`). В логе (`[like] 403: … права токена: …`) видно, какие права у токена на самом деле. Нажмите «Выйти», затем «Войти через Spotify» заново и подтвердите доступ — право появится. Старый refresh-токен навсегда сохраняет права, выданные при первом входе, поэтому повторный вход обязателен.
- «Лог плагина», «Войти» и «Выйти» работают в настройках **любой** кнопки плагина.
- Настройки каждой кнопки сохраняются отдельно, меняются **по одному полю** (не сбрасывая остальные) и применяются к той кнопке, чью панель вы открыли (даже если таких кнопок несколько).
- Громкость, как и всё управление воспроизведением, требует **Spotify Premium** и активного устройства.
- Кнопки обновляются автоматически (~1–2 сек). Информация о треке берётся из вашего аккаунта: работает на любом устройстве, где играет Spotify (ПК, телефон, колонка).
- Если ничего не играет — на кнопках показывается затемнённая иконка, при нажатии появится предупреждение.
- Вход в аккаунт и токены хранятся в глобальных настройках StreamDock и в файле `%USERPROFILE%\.spotify-control-streamdock.json`. Кнопка «Выйти» удаляет токены.

## Если что-то не работает

Плагин пишет подробный лог (все сообщения StreamDock с содержимым payload, шаги входа, ошибки, сводка состояния каждые 30 сек, реальные права токена `[scopes]`).
Посмотреть лог можно прямо в панели настроек: кнопка **«Лог плагина»** внизу → «Копировать».
При обращении за помощью пришлите свежие строки с метками `[scopes]`, `[summary]`, `[like]` и `[settings]` — по ним сразу видно и причину, и что плагин реально получил.

- **Кнопка «Войти» не реагирует** — нажмите «Лог плагина»:
  - лог показывает «Плагин запущен…» и сообщения — плагин работает, пришлите содержимое лога;
  - «Нет связи с плагином» или лог пуст — плагин не запускается. Убедитесь, что папка плагина лежит именно в `%APPDATA%\HotSpot\StreamDock\plugins`, полностью перезапустите StreamDock (из трея). Если не помогло — пришлите лог из файла `%TEMP%\spotify-control-plugin.log`.
- **Лог пуст или файла нет** — StreamDock не запускает Node-плагины (возможно, старая версия софта). Обновите StreamDock.
- **«Invalid redirect URI»** — адрес в поле плагина должен точно совпадать с адресом в настройках приложения Spotify (включая порт): `http://127.0.0.1:8888/callback`.
- **Порт 8888 занят** — поменяйте порт в обоих местах (поле Redirect URI в плагине и настройки приложения Spotify), например на `8899`.

## Сборка ZIP (если нужен архив)

На Windows: выделите папку `com.spotify.control.sdPlugin` → ПКМ → **Сжать в ZIP-архив**.
